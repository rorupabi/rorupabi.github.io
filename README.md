# Rouen Padilla — Portfolio

My personal portfolio website, built to showcase my work as a web developer.

🔗 **Live site:** [rorupabi.github.io](https://rorupabi.github.io)

## Tech Stack

**Frontend** (`/front`)
- React 19
- Vite
- Tailwind CSS
- Framer Motion

**Backend** (`/back`)
- Node.js + Express
- Nodemailer (handles the contact form)

## Getting Started

### Frontend
```bash
cd front
npm install
npm run dev
```

### Backend
```bash
cd back
npm install
```
